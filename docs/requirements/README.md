# Product requirements

DialyCore's product requirements and workflow model were shaped with input from professionals familiar with hemodialysis-unit operations. This directory records how that domain input has been translated into the current institution-neutral reference application.

These documents describe software scope, not universal clinical protocol. Dialysis practices, terminology, permissions, record-retention rules, and regulatory obligations vary by organization and jurisdiction. Contributors proposing clinical-workflow changes should explain the domain basis, identify assumptions, and keep institution-specific behavior configurable where practical.
